# Virasoro-Extremal-Projector
This code is for exact symbolic computation of the Virasoro extremal projector components $P[n]$, the partial projectors $P_N = \sum_{n=0}^N P[n]$, the Shapovalov matrices $S^{(n)}(L_0, c)$, the primitive Kac polynomials $K_n(L_0, c)$, and the exact $N$-th regularizing denominators $D_N(L_0, c)$ over $\mathbb{Q}(L_0, c)$.
